Unordered List

 We use <ul> tag to create an unordered list and use <li> for indicating the lists as follows
  • module 1
  • module 2
  • module 3

Ordered List

 <ol> tag is used to create an ordered list which results in a 1, 2, 3... sequence. and for the
 list we use <li> tag as follows
  1. module 5
  2. task 3
  3. Assignment 2

Nested List

 Nested list is a list inside another list. We can create a nested list by 
 putting an unordered or ordered list inside an <li> tag of another list as follows
  • orderded lists
    1. module one
    2. module two
    3. module three
  • unordered lists
    • task one
    • task two
      1. assignment one
      2. assignment two
      3. assignment three
        • sub task one
        • sub task two
        • sub task three
    • task three
