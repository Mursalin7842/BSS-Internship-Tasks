Learning Meta Tags

            Charset:  The charset meta tag specifies the character encoding for the HTML document. It ensures that the text is displayed correctly in different browsers and devices.
            The most common character encoding is UTF-8, which supports a wide range of characters from various languages.

            Viewport:  The viewport meta tag is used to control the layout and scaling of a web page on different devices, 
            especially mobile devices. It allows you to specify the width and initial scale of the viewport, 
            ensuring that the content is displayed correctly on various screen sizes.

            Description:  The description meta tag provides a brief summary of the content of the web page. 
            It is often used by search engines to display a snippet of the page in search results.

            Keywords:  The keywords meta tag allows you to specify a list of relevant keywords that describe the content of the web page.
            
            Author:  The author meta tag specifies the name of the author or creator of the web page. 
            It can be used to provide credit to the individual or organization responsible for the content.
            
            Robots:  The robots meta tag is used to control how search engine crawlers index and follow the web page. 
            It can be used to specify whether the page should be indexed, whether links should be followed, or if certain pages should be excluded from search results.
